# Story

Automation used to be mostly about making machines do things.

AI agents change the equation: machines can increasingly decide what to ask machines to do. The missing layer is control.

OpenOps treats an agent's tool call as a proposal, not an unrestricted capability. Policy decides whether it is allowed, risk makes the reasoning visible, approval adds human control when required, deterministic execution performs the action, and audit records the lifecycle.

The goal is not autonomous control. It is a narrow, inspectable boundary around consequential automation.
